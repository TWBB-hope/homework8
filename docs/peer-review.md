## 五、我在本次审查中的自查发现（供对照同学意见）

| 序号 | 发现的问题 | 处理情况 |
| --- | --- | --- |
| 1 | 三维子页若与主页面同时打开，切回后台标签时渲染循环仍在跑，会造成卡顿 | 已在两个 `scene.js` 中用 `visibilitychange` 停止/恢复 `requestAnimationFrame`（见 `integration/three-d/scene.js` 末尾） |
| 2 | 图表库全局判断写成 `typeof window.echarts === 'function'`，而 ECharts 5 的全局对象是 object，会误判为"库未加载" | 已改为判断 `window.echarts && typeof window.echarts.init === 'function'`（`integration/js/app.js` 的 `chartUnavailable`）；Three.js 同理改为判断 `window.THREE && window.THREE.Scene` |
| 3 | Chart.js 与 ECharts 用法不同：Chart.js 必须拿到 `<canvas>`，直接给它 `div` 会报"can't acquire context from the given item" | 已把 `practice/index.html` 的图表容器改为 `.chart-box > canvas` |
| 4 | 拥挤度只靠颜色深浅区分不符合可访问性要求 | 已同时输出"紧张/适中/宽松"文字与百分比 |
| 5 | 筛选后旧列表残留 | `renderTable`/`renderRooms` 渲染前先 `innerHTML = ''`（或 jQuery `.empty()`）再整体替换 |
